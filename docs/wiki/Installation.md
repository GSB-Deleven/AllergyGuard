# Installation aufs iPhone

AllergyGuard ist eine Web-App. Du installierst sie direkt aus Safari, ohne App Store und gratis.

## iPhone (Safari)
1. **Safari** öffnen und **https://gsb-deleven.github.io/AllergyGuard/** aufrufen.
2. Unten auf **Teilen** tippen (Quadrat mit Pfeil nach oben).
3. Nach unten scrollen → **Zum Home-Bildschirm** → **Hinzufügen**.
4. AllergyGuard **vom Home-Bildschirm** starten (nicht aus Safari). Nur so bleiben die Daten zuverlässig gespeichert.

## Android (Chrome)
1. Link in **Chrome** öffnen.
2. Menü **⋮** → **App installieren** bzw. **Zum Startbildschirm hinzufügen**.

## Danach unbedingt
- **Info (ⓘ) → Für unterwegs vorbereiten** (im WLAN, ca. 27 MB). Dann klappt das Zutaten-Foto auch offline.
- **Profil → Sicherung speichern** → in iCloud Drive ablegen. Wird die App gelöscht, sind sonst alle Profile weg.
- **Zweites Handy:** App installieren → **Profil → Profil-QR scannen** → QR-Code vom ersten Handy scannen.

## Updates
Passieren automatisch. Neue Versionen werden beim Öffnen im Hintergrund geladen und sind beim nächsten Start aktiv.
