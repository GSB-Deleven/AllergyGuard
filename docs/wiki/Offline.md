# Offline

AllergyGuard funktioniert grösstenteils ohne Internet, etwa in der Tiefgarage, im Flugzeug oder im Ausland ohne Daten.

| Funktion | Offline? |
|---|---|
| App öffnen, Profile, Verlauf | ✅ |
| Allergie-Karte inkl. Vorlesen | ✅ |
| Wörter-Check | ✅ |
| Zutaten-Foto | ✅ nach „Für unterwegs vorbereiten“ |
| Schon einmal gescannte Produkte | ✅ aus dem Speicher |
| Neue Barcodes | ⏳ werden gemerkt und automatisch geprüft, sobald du online bist |

## Vorbereiten
**Info (ⓘ) → Für unterwegs vorbereiten**, am besten im WLAN (ca. 27 MB).

## Wichtig beim iPhone
- App **vom Home-Bildschirm** nutzen. Safari löscht Daten von Websites, die länger nicht besucht wurden. Bei Home-Bildschirm-Apps passiert das nicht bzw. viel seltener.
- Regelmässig **Sicherung speichern**.
