# Datenschutz

**Kurz:** Deine Daten bleiben auf deinem Handy.

| Was | Wo |
|---|---|
| Profile (Namen, Allergene, Spuren-Stufe) | nur auf dem Gerät (Browser-Speicher) |
| Verlauf, gespeicherte Produkte | nur auf dem Gerät |
| Fotos von Zutatenlisten | werden auf dem Gerät ausgewertet, nie hochgeladen |
| Barcode-Nummer | wird an Open Food Facts gesendet, um das Produkt zu finden |
| Standort | nur auf Knopfdruck, wird auf dem Gerät ausgewertet, nie gesendet |

- Kein Konto, keine Cookies, keine Werbung, kein Tracking, keine Analyse-Dienste.
- Keine externen Schriften oder CDNs: Alle Dateien kommen von GitHub Pages.
- **Profil teilen per QR-Code:** Die Daten stehen im Link hinter dem `#`. Dieser Teil wird technisch nie an einen Server geschickt.
- **Sicherung:** Die Datei enthält Profile und Verlauf. Bewahre sie so auf wie andere persönliche Dokumente.
- Open Food Facts ist eine gemeinnützige Organisation aus Frankreich: [Datenschutz von Open Food Facts](https://world.openfoodfacts.org/privacy).
